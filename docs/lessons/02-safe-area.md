# Safe Area：让内容避开系统区域

## 核心原则

内容和交互元素应该依赖安全区与布局边距，而不是自行猜测摄像头、侧边控件或折叠区域的位置。这样可以让系统在不同姿态下为内容自动保留空间。

## 本项目中的实验

学习详情页使用滚动容器和容器内边距承载内容。安全区实验使用 `GeometryReader.safeAreaInsets` 显示当前容器的安全区，并提供 `safeAreaInset(edge:)` 与普通 overlay 的对比，说明底部交互内容应该交给安全区布局管理。

## 验证清单

- 交互元素是否可能被侧边控件遮挡？
- 内容变窄时，文字是否会被截断？
- 半折时，按钮等交互元素是否落在中央折痕上？
- 是否错误地使用了屏幕尺寸代替容器尺寸？
- 使用 `safeAreaInset` 后，底部操作是否仍然保持可见、可点击？
