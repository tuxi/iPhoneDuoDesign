# Inner Display：使用双栏展示指南

## 核心原则

内屏提供了更多横向空间，但不应该只是把外屏内容拉伸。适合分层阅读的内容，可以同时展示章节列表和当前详情，让用户更快理解上下文。

## 本项目中的实验

这个实验直接使用 iPhone Duo Design Guide 作为内容：

- 左侧显示指南章节列表；
- 右侧显示当前章节的设计原则和要点；
- 窄空间下，`NavigationSplitView` 会收起为单栏导航；
- 章节选择和内容层级保持一致。

## 验证清单

- 宽空间是否同时展示列表和详情？
- 窄空间是否仍然可以访问所有章节？
- 当前章节切换后，详情内容是否同步更新？
- 内屏是否真正展示了更多上下文，而不是单纯放大文字？
- 列表和详情是否保持同一份内容模型？
