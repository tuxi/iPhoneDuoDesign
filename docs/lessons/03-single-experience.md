# Single Experience：保持状态连续

## 核心原则

用户可能在使用过程中打开、关闭或改变设备姿态。布局可以根据空间发生变化，但功能、层级和状态应该保持一致，不能因为切换姿态而变成两套互不相关的界面。

## 本项目中的实验

实验使用同一份状态模型保存当前页面、固定状态和笔记内容：

- 空间足够时，使用左侧页面选择器和右侧内容；
- 空间不足时，使用菜单选择器和下方内容；
- 两种布局共享同一组 `@State`，因此切换布局不会丢失状态。

这里使用 `ViewThatFits` 观察布局变化，而不是根据某个具体屏幕宽度写死分支。

## 验证清单

- 切换页面后，内容是否保持对应关系？
- 改变“固定这个页面”开关后，布局变化时开关是否保持？
- 在笔记输入框中输入内容后改变窗口大小，文字是否仍然存在？
- 宽布局和窄布局是否表达相同的功能和层级？
