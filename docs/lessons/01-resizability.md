# Resizability：让布局自由缩放

## 核心原则

不要围绕某一个具体屏幕尺寸或某一种姿态写死布局。应该让界面根据容器提供的空间自然变化，并使用 compact 和 regular 两种尺寸等级理解外屏与内屏的主要差异。

## 本项目中的实验

当前 App 使用 `NavigationSplitView` 作为学习目录容器。它让同一套导航结构在较窄空间中收起，在较宽空间中展示列表和详情，适合作为第一个自适应布局示例。

## 验证清单

- 是否存在依赖具体屏幕宽度的固定布局？
- 窗口变窄时，内容是否仍然可读、可点击？
- 窗口变宽时，是否只是拉伸，而没有利用额外空间？
- 内外屏切换后，导航层级和当前状态是否保持一致？
